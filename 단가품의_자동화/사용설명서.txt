[거래처별구매단가품의 분기별 자동 생성]

■ 가장 쉬운 방법: 단가품의_생성.html (설치 필요 없음)
  1) 단가품의_생성.html 을 더블클릭 (크롬/엣지에서 열림)
  2) ① 입고내역(프로젝트구매입고품목조회) 과 ② 등록단가(구매단가조회) 엑셀을 선택
     - 협의로 확정한 단가가 있으면 ③ 수기조정 파일(수기조정_양식.xlsx 형식) 선택
  3) [품의 파일 만들기] → [품의 파일 다운로드], [검토자료 다운로드]
  * 파일은 이 컴퓨터 안에서만 처리되며 인터넷으로 전송되지 않습니다.
  * 연도/분기는 입고일로 자동 인식합니다.

■ (참고) 파이썬 버전: 단가품의_생성.py  (pip install openpyxl 후 사용, 결과는 HTML과 동일)

■ 결과 파일
  · {연도}년_{분기}분기_거래처별구매단가품의.xlsx : 2분기 양식과 동일한 품의 파일
  · {연도}년_{분기}분기_품의_검토자료.xlsx : 요약 / 확인필요 / 포함내역 / 제외내역

■ 작성 규칙 (2분기 실제 파일과 대조해 역산)
  - 입고내역을 품번+구매거래처별로 묶고, 최신 입고(입고일 → 입고번호 → 같은 입고번호에서 수량이 가장 큰 라인)의 입고원화단가를 단가로 사용
  - 제외: PSC 90번대(P-9로 시작) / 품명·규격에 수리, 운송비, 기업이윤, 일반관리비, 개조, 수정, 인건 포함
    (2026-10: 수정/인건비도 제외로 변경. 화면의 제외 단어에서 가감 가능)
  - 등록단가와 같은 단가(변동 없음)는 제외, 단가가 다르거나 미등록 신규 품번은 포함
  - [2026-10 개선] 이미 등록된 건은 품의에 다시 올리지 않음
    · 적용시작일이 분기말 다음날~2개월 이내 1일자(예: 3분기 품의 → 10/01)로 이미 등록된 건 → 제외
    · 등록단가의 최종작업일 이전에 발주(또는 입고)된 건은 '옛 단가'이므로 단가변경으로 보지 않고 제외
      (예: R-10A-02013 7/9 입고 39,240 vs 8/19 등록 43,600 → 제외). 기준일은 화면에서 발주일/입고일 선택
    · 제외된 건 중 입고단가와 등록단가가 다른 건은 검토자료 [확인필요]에 표시 → 필요시 수기조정 파일로 추가
    · 과거 품의를 등록 이후 파일로 다시 만들어 검증하려면 화면의 '이미 등록된 품의분도 다시 포함' 체크(py: --include-registered)
  - 거래처별로 단가가 다를 수 있으므로 (품번+거래처) 단위로 비교. 품번은 등록돼 있어도 이 거래처로 미등록이면
    입고 거래처 단가로 "신규" 등록 (검토자료 [신규거래처(참고)] 시트에 기존 등록 거래처·단가와 차이율 표시)
  - 신규 품번이 여러 거래처로 입고되면 거래처별로 모두 포함
  - 검토자료 [확인필요]는 판단이 필요한 건만 표시 (등록 이전 입고분 제외건 / 이미 등록건 단가상이 / 신규 0원)
  - 구분(J열): [품번 기준] 현재 등록단가에 품번이 없음 = 신규, 품번이 이미 등록돼 있으면 거래처가 달라도 = 변경(기존)
  - 단위(I열) = EA 고정, 증감률(K열) = (품의단가-등록단가)/등록단가, ▲ 인상 / ▼ 인하 (신규는 공란)
  - 적용시작일/단위는 원본처럼 공란 (화면에서 적용시작일 입력 시 일괄 입력)
